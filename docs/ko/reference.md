# 문법과 자주 만나는 문제

코드를 작성하다 문법이 기억나지 않을 때 찾아보는 페이지입니다. 각 주제의 상세한 설명과 실행 코드는 연결된 장에 있습니다.

## 문법 빠르게 찾기

| 원하는 작업 | 쓰는 형태 | 읽을 장 |
| --- | --- | --- |
| 값 이름 붙이기 | `let name: Type = value;` | [변수와 값](language-basics.md) |
| 바꿀 수 있는 변수 | `let mut name = value;` | [변수와 값](language-basics.md) |
| 함수 선언 | `fn name(x: Int) -> Int { return x; }` | [함수](control-flow.md) |
| 조건 값 | `if condition { yes } else { no }` | [함수와 반복](control-flow.md) |
| 범위 반복 | `for item in start..end { ... }` | [함수와 반복](control-flow.md) |
| 조건 반복 | `while condition { ... }` | [함수와 반복](control-flow.md) |
| 배열처럼 값 나열 | `[first, second]`, `Vec<T>` | [컬렉션](collections.md) |

함수·구조체·enum·impl은 파일 최상위에 선언합니다. 값과 문장은 함수 안에 씁니다. 문장에는 `;`을 붙이고 값으로 쓰는 `if`·`match`의 마지막 표현식은 붙이지 않습니다. 주석은 `//`만 지원하며 블록 주석은 없습니다. 이름과 문자열은 대소문자를 구분합니다.

## 숫자와 연산자

정수는 `I8`~`I64` 및 `U8`~`U64`, 실수는 `F32`, `F64`입니다. `Int = I64`, `Float = F64`입니다. 숫자 리터럴은 10진수이며 실수는 `1.25`, `1e3`처럼 쓸 수 있습니다. 숫자 사이의 `_`와 16진수 리터럴 문법은 없습니다.

우선순위는 높은 것부터 호출·필드·색인·`?`, 거듭제곱 `**`, 단항 `+ - ! ~ & *`, `* / %`, `+ -`, `<< >>`, `&`, `^`, `|`, `< <= > >=`, `== !=`, `&&`, `||`입니다. `**`는 오른쪽부터, 다른 같은 단계의 이항 연산자는 왼쪽부터 묶입니다. 따라서 `2 ** 3 ** 2`는 `512`, `-2 ** 2`는 `-4`, `(-2) ** 2`는 `4`입니다. 지수에는 `2.0 ** -2.0`처럼 단항 부호를 쓸 수 있습니다. 헷갈리면 괄호를 사용하세요. 문자열에는 `+`, `==`, `!=`를 사용할 수 있습니다. 벡터의 비교는 비교 가능한 숫자·Bool·String·중첩 벡터 원소에 한해 지원합니다. 구조체와 enum에는 `==`가 없습니다.

| 연산자 | 피연산자와 결과 |
| --- | --- |
| 단항 `+` | 모든 숫자 타입. 실수의 음수 0을 포함해 값을 그대로 반환 |
| 단항 `-` | signed 정수 또는 실수. 정수는 타입 폭에서 wrap |
| `+ - * /` | 같은 타입의 숫자 둘. 정수 `+ - *`는 wrap하고 정수 나눗셈은 0 방향으로 버림 |
| `%` | 같은 타입의 숫자 둘. 나머지의 부호는 나누어지는 수를 따름 |
| `**` | 같은 타입의 숫자 둘. 실수 지수를 포함하는 거듭제곱 |
| `& \| ^`, 단항 `~` | 정수의 비트 AND·OR·XOR와 타입 폭에 맞춘 비트 반전 |
| `<< >>` | 같은 타입의 정수 둘. 결과도 같은 타입 |
| `&& \|\|`, 단항 `!` | `Bool`. `&&`와 `\|\|`는 필요할 때만 오른쪽을 평가 |

시프트 개수는 `0 이상, 타입의 비트 수 미만`이어야 합니다. 범위를 벗어나면 결과를 쓰지 않아도 실행 오류가 납니다. 왼쪽 시프트는 타입 폭을 넘는 비트를 버립니다. 오른쪽 시프트는 signed 타입에서 부호를 유지하고 unsigned 타입에서 0을 채웁니다. 예를 들어 `i8(-8) >> i8(2)`는 `-2`, `u8(128) >> u8(2)`는 `32`입니다. 시프트와 비트 연산의 두 피연산자는 같은 정수 타입이어야 하며, 리터럴은 문맥에서 타입을 받습니다. `let mask: U8 = 1 << 7;`처럼 쓸 수 있고 일반 스코프에서도 지원합니다.

정수의 0으로 나누기·나머지 연산, signed 최솟값을 `-1`로 나누거나 나머지를 구하는 연산은 실행 오류입니다. 단항 `&`는 빌림이고 이항 `&`는 비트 AND입니다.
접두 위치의 `**ref`는 기존처럼 이중 역참조입니다. 역참조한 값과 곱하려면 `value * *ref`처럼 적으세요.

정수 거듭제곱은 반복 제곱법으로 계산하고 결과 타입의 폭에서 wrap합니다. 음수 정수 지수는 결과를 쓰지 않아도 실행 오류이며, `0 ** 0`은 `1`입니다. 음수·소수 지수에는 실수 피연산자를 사용하세요. `2.0 ** -3.0`은 `0.125`, `9.0 ** 0.5`는 `3.0`입니다.

실수 `%`는 몫을 0 방향으로 버린 나머지를 정확히 구하되, 실수로 몫을 직접 계산하지 않습니다. 0으로 나머지 구하기, 무한대인 피제수, NaN 피연산자는 NaN을 반환합니다. 유한한 수를 무한대로 나머지 구하면 원래 값을 반환하고, 나머지가 0이면 피제수의 부호를 유지합니다. 실수 `**`는 IEEE 특수값 규칙을 따릅니다. 음수 유한 밑에 정수가 아닌 지수를 적용하면 NaN, overflow는 부호 있는 무한대, underflow는 부호 있는 0이 될 수 있습니다. `NaN ** 0.0`과 `1.0 ** NaN`은 `1.0`입니다. 두 CPU는 공통 binary64 수치 루틴을 사용합니다. F32는 피연산자를 정확히 F64로 넓혀 계산한 뒤 무한대·NaN을 포함해 F32로 반올림합니다.

## 흔한 오류와 수정

| 상황 | 수정 |
| --- | --- |
| 빈 벡터의 타입을 알 수 없음 | `let values: Vec<Int> = [];`처럼 타입 추가 |
| 변경할 수 없는 변수 | 변경해야 한다면 `let mut`으로 선언 |
| 서로 다른 숫자 타입 | `i32(...)` 등으로 명시적으로 변환 |
| 빠진 match 갈래 | 빠진 enum 형태를 추가하거나 적절한 `_` 사용 |
| 제네릭 타입 추론 실패 | 인자에 타입 정보를 주거나 모든 타입 인자 명시 |
| 빌린 값 변경 | 참조의 마지막 사용 이후 변경 |
| 이미 이동한 값 사용 | 새 소유자를 사용하거나 이동 전에 필요한 정보 읽기 |
| 모듈을 찾을 수 없음 | 시작 파일 기준 경로와 `module` 이름 확인 |
| 범위 밖 원소 읽기 | 접근 전 길이 검사 |

이동한 값을 사용하는 다음 코드는 의도적인 오류입니다.

```xen
fn main() {
    let original = box(42);
    let transferred = original;
    println(original.into_inner());
}
```

```sh
xen check move_error.xen
```

`moved`를 포함하는 오류가 납니다. 마지막 줄을 `println(transferred.into_inner());`로 바꾸면 42를 출력합니다.

## 기능을 찾을 수 없을 때

현재 클로저·trait·예외·async·FFI·패키지 관리 기능은 없습니다. 참조 반환, 가변 Slice, 문자열 색인, match guard도 지원하지 않습니다. 다른 언어의 문법을 그대로 쓰기보다는 해당 장에서 설명한 함수·반복·`Result`를 사용하세요.

[`bb` 저수준 기능](low-level.md)은 원시 메모리, 운영체제 호출, 범위가 있는 주소, volatile·정수 원자 접근, CPU 힌트·장벽, 다중 출력 인라인 `asm`, 스칼라 C ABI `extern_call`을 지원합니다. 일반적인 파일·입출력·경로 작업은 표준 라이브러리 API를 사용하세요.
